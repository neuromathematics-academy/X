# NeuroMath Academy Website

## Included
- `index.html` — responsive single-page academy website
- `styles.css` — custom premium navy/blue/gold styling
- `script.js` — registration email handoff and navigation behavior
- `assets/neuromath-logo.jpg` — uploaded academy logo

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Bootstrap and Google Fonts CDNs.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
3. In repository Settings → Pages, choose Deploy from a branch and select the `main` branch / root folder.
4. Save and wait for GitHub Pages to publish.

## Registration form note
The current form uses a `mailto:` handoff to `neuromathematics.academy@gmail.com`. It does not store submissions in a database. For automatic collection, connect a secure form backend (for example, Formspree, Google Forms, or your own server) and add its endpoint.

## Before publishing
- Replace the faculty photo placeholder with the faculty photograph.
- Confirm course fees, batch timings, class schedule, syllabus coverage, and any eligibility details before adding them.
- The website describes the course details supplied in the conversation. It does not claim a Singapore headquarters or unverified institutional affiliations.
- Verify the event date and stream link before promoting.
